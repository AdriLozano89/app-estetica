FUENTES PARA TARJETAS REGALO, FACTURAS Y CONSENTIMIENTOS (opcional pero recomendado)
====================================================================================

La web usa Google Fonts directamente en el navegador, no necesita nada aquí.

Las imágenes y PDF que genera Python (tarjeta regalo, factura, consentimiento) buscan
estos archivos en esta carpeta. Si no existen, usan una fuente serif cursiva del sistema
y todo funciona igual, solo cambia el estilo caligráfico.

Descarga (licencia libre OFL) desde https://fonts.google.com y copia aquí:

  GreatVibes-Regular.ttf                 -> firma caligráfica de la marca
  CormorantGaramond-Regular.ttf          -> títulos elegantes
  CormorantGaramond-SemiBold.ttf
  CormorantGaramond-Italic.ttf
  Montserrat-Regular.ttf                 -> texto limpio
  Montserrat-Medium.ttf
  Montserrat-SemiBold.ttf

Si tienes el logotipo real, guárdalo como assets/logo.png (fondo transparente, color dorado
o blanco) y se usará como marca de agua en la tarjeta regalo.
